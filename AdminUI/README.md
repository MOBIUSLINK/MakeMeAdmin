## 概述

**Make Me Admin AdminUI** 是 Make Me Admin 系统的管理端审批界面，用于管理员审核用户提交的临时管理员权限请求。当系统启用审批流程后，所有用户请求都需要管理员在此界面中批准或拒绝。

### 主要功能
- ✅ 查看所有待审批的权限请求
- ✅ 批准或拒绝用户请求
- ✅ 实时刷新请求列表
- ✅ 显示请求详细信息（用户名、时间、超时设置、来源）

## 编译说明

### 方法一：使用 Visual Studio 2022 编译

#### 步骤 1：打开解决方案
1. 启动 Visual Studio 2022
2. 选择 **文件** → **打开** → **项目/解决方案**
3. 导航到项目根目录，选择 `MakeMeAdmin.sln` 文件
4. 点击 **打开**

#### 步骤 2：配置项目
1. 在 **解决方案资源管理器** 中找到 `AdminUI` 项目
2. 右键点击 `AdminUI` 项目，选择 **属性**
3. 在 **应用程序** 选项卡中确认：
   - **目标框架**：`.NET Framework 4.8`
   - **输出类型**：Windows 应用程序
4. 在 **生成** 选项卡中选择目标平台：
   - **x64**（推荐，适用于 64 位系统）
   - **x86**（适用于 32 位系统）

#### 步骤 3：还原 NuGet 包（如需要）
1. 右键点击解决方案
2. 选择 **还原 NuGet 包**
3. 等待还原完成

#### 步骤 4：编译项目
1. 在 **解决方案配置** 下拉菜单中选择：
   - **Debug**（调试版本，包含调试信息）
   - **Release**（发布版本，优化后的版本）
2. 在 **解决方案平台** 下拉菜单中选择：
   - **x64** 或 **x86**
3. 选择菜单 **生成** → **生成解决方案** (快捷键: `Ctrl+Shift+B`)
4. 等待编译完成

#### 步骤 5：检查编译结果
编译成功后，可执行文件位于：
- **Debug 版本**：`AdminUI\bin\Debug\x64\MakeMeAdminAdminUI.exe`（或 `x86`）
- **Release 版本**：`AdminUI\bin\Release\x64\MakeMeAdminAdminUI.exe`（或 `x86`）

## 使用指南

### 启动程序

#### 方式一：直接运行
1. 找到 `MakeMeAdminAdminUI.exe` 文件
2. **右键点击**，选择 **以管理员身份运行**

```

│                                                           │

```

#### 界面元素说明
- **请求列表**：显示所有待审批的权限请求
  - **用户名**：提交请求的用户账户名
  - **请求时间**：用户提交请求的时间
  - **超时时间**：请求的管理员权限持续时间（分钟）
  - **远程地址**：显示"本地"或远程计算机IP地址
- **批准按钮**：批准选中的请求
- **拒绝按钮**：拒绝选中的请求
- **刷新按钮**：手动刷新请求列表
- **状态标签**：显示当前待审批请求的数量

### 操作流程

#### 1. 查看待审批请求
- 程序启动后会自动加载待审批请求列表
- 列表按请求时间倒序排列（最新的在最上面）
- 程序每 5 秒自动刷新一次

#### 2. 批准请求
1. 在请求列表中**单击**选择要批准的请求
2. 点击 **批准** 按钮
3. 在弹出的确认对话框中点击 **是**
4. 系统会立即批准请求，用户将获得管理员权限
5. 请求从列表中移除

#### 3. 拒绝请求
1. 在请求列表中**单击**选择要拒绝的请求
2. 点击 **拒绝** 按钮
3. 在弹出的确认对话框中点击 **是**
4. 请求被拒绝，用户不会获得管理员权限
5. 请求从列表中移除

#### 4. 手动刷新
- 点击 **刷新** 按钮可立即刷新请求列表
- 程序也会自动每 5 秒刷新一次

### 使用示例

#### 场景一：批准单个请求
```
1. 用户 "DOMAIN\John" 提交了管理员权限请求
2. 管理员打开 AdminUI，看到请求出现在列表中
3. 管理员选择该请求，点击"批准"
4. 确认后，John 立即获得管理员权限
5. 请求从列表中消失
```

#### 场景二：批量处理多个请求
```
1. 管理员打开 AdminUI，看到 3 个待审批请求
2. 管理员逐一查看每个请求的详细信息
3. 对于合理的请求，点击"批准"
4. 对于不合理的请求，点击"拒绝"
5. 所有请求处理完成后，列表为空
```

## 功能说明

### 自动刷新机制
- **刷新间隔**：每 5 秒自动刷新一次
- **刷新内容**：重新从服务获取所有待审批请求
- **手动刷新**：可随时点击刷新按钮立即刷新

### 请求信息显示
- **用户名**：显示完整的 Windows 账户名（格式：DOMAIN\UserName）
- **请求时间**：显示用户提交请求的日期和时间
- **超时时间**：显示管理员权限的持续时间（分钟）
- **远程地址**：
  - 显示"本地"表示本地用户请求
  - 显示 IP 地址表示远程用户请求

### 审批操作
- **批准**：
  - 立即将用户添加到本地管理员组
  - 设置权限超时时间
  - 记录审批日志
  - 从待审批列表中移除
- **拒绝**：
  - 不授予管理员权限
  - 记录拒绝日志
  - 从待审批列表中移除

### 错误处理
- **服务连接失败**：显示错误提示，提示检查服务是否运行
- **操作失败**：显示具体错误信息，便于排查问题
- **网络问题**：自动重试连接

## 常见问题

### Q1: 程序无法启动，提示"无法连接到服务"
**原因**：Make Me Admin 服务未运行或无法访问

**解决方法**：
1. 检查服务是否运行：
   ```batch
   sc query "Make Me Admin"
   ```
2. 如果服务未运行，启动服务：
   ```batch
   net start "Make Me Admin"
   ```
3. 确保以管理员身份运行 AdminUI

### Q2: 列表中没有显示任何请求
**可能原因**：
- 没有用户提交请求
- 审批流程未启用
- 服务配置问题

**解决方法**：
1. 确认审批流程已启用（默认已启用）
2. 让用户提交一个测试请求
3. 检查服务日志文件

### Q3: 批准/拒绝操作失败
**可能原因**：
- 权限不足
- 服务异常
- 请求已被其他管理员处理

**解决方法**：
1. 确保以管理员身份运行程序
2. 检查服务状态
3. 点击刷新按钮更新列表
4. 查看 Windows 事件日志

### Q4: 程序界面显示乱码
**原因**：系统区域设置或字体问题

**解决方法**：
1. 检查系统区域设置是否为中文（简体）
2. 确保系统已安装中文字体
3. 重新编译项目

### Q5: 编译时出现"找不到类型或命名空间"错误
**原因**：项目引用缺失或未编译依赖项

**解决方法**：
1. 右键解决方案，选择"还原 NuGet 包"
2. 右键解决方案，选择"生成解决方案"
3. 确保所有依赖项目都已编译成功

### Q6: 如何禁用审批流程？
**方法**：修改注册表（需要管理员权限）
1. 打开注册表编辑器（regedit）
2. 导航到：`HKEY_LOCAL_MACHINE\SOFTWARE\Sinclair Community College\Make Me Admin`
3. 创建或修改 DWORD 值：`Require Approval` = `0`
4. 重启 Make Me Admin 服务

**注意**：禁用审批流程后，用户请求将直接获得权限，无需审批。

## 技术架构

### 项目结构
```
AdminUI/
├── AdminApprovalForm.cs          # 主窗体类
├── AdminApprovalForm.Designer.cs  # 窗体设计器
├── Program.cs                     # 程序入口点
├── Properties/
│   ├── Resources.resx            # 资源文件
│   ├── Resources.Designer.cs     # 资源设计器
│   └── AssemblyInfo.cs           # 程序集信息
├── Resources/
│   └── SecurityLock.ico          # 应用程序图标
└── App.config                     # 应用程序配置
```

### 依赖项目
- **ProcessCommunication**：提供 WCF 服务接口
  - `IAdminGroup`：服务契约接口
  - `PendingRequest`：待审批请求数据结构
- **Shared**：共享功能
  - `Shared.NamedPipeServiceBaseAddress`：服务地址
- **UserList**：用户管理功能

### 通信机制
- **通信方式**：WCF Named Pipe（本地命名管道）
- **服务地址**：`net.pipe://localhost/MakeMeAdmin/Service`
- **安全模式**：Transport（传输层安全）

### 数据流
```
用户请求 → Make Me Admin 服务 → 保存为待审批请求
                                    ↓
管理员操作 ← AdminUI ← 获取待审批列表
    ↓
批准/拒绝 → 服务处理 → 更新用户权限
```
